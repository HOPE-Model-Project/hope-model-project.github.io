# HOPE Model Project website

Public website for the **Holistic Optimization Program for Electricity (HOPE)**.

## Local preview

The site is dependency-free. Serve the repository root with any static file server:

```bash
python -m http.server 4173
```

Then open <http://localhost:4173>.

## Deployment

The repository is published as the HOPE-Model-Project organization site with GitHub Pages.
